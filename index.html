경험을 설명하는 대신,
작업을 먼저 보여주세요.

짧은 소개와 실제 작업을 연결하는
포트폴리오 전용 편집기입니다.

이 기기의 브라우저에 자동 저장
기본 인물과 작업은 가상 예시입니다. 실제 수행한 작업과 역할을 구분해 수정하세요.

선택한 작업들

첫 번째 작업이 대표 작업입니다.
최대 12개, 작업마다 대표 이미지와 상세 사진 2장을 넣을 수 있습니다.

사진은 직접 촬영했거나 공개 권한을 가진 JPEG·PNG·WebP, 장당 10MB 이하만 사용하세요. 원본은 바꾸지 않고 사본을 포함합니다.

보여줄 근거를,
정확하게 남기세요.

이 포트폴리오의 구성

짧은 소개 → 대표 작업 → 분야별 작업 목록 → 작업별 상세 → 나의 관점 → 연락처

  1. 프로필 수정
    이름, 활동 분야, 소개, 실제 연락처를 입력합니다.
  2. 작업 추가와 편집
    작업 제목·분야·내 역할·기간·도구를 적고, 출발점·접근·결과를 구체적으로 설명합니다. 작업 순서를 바꾸거나 ‘대표로’를 눌러 가장 중요한 작업을 앞에 둡니다.
  3. 이미지와 링크
    대표 이미지는 목록에, 상세 이미지 2장은 작업 상세에 보입니다. 실제 영상·음악·문서·사이트의 공개 링크를 연결할 수 있습니다.
  4. 가상 예시와 실제 작업 구분
    기획만 한 예시는 실제 수행·납품·성과처럼 소개하지 마세요. 작업별 예시 표시와 전체 템플릿 안내는 별도입니다. 안내를 끈다고 예시 문구가 자동으로 바뀌지는 않습니다.
  5. JSON과 HTML 저장
    JSON은 다시 편집하는 백업, index.html은 공개용 독립 포트폴리오입니다. 저장만으로 온라인에 공개되지는 않습니다.

백업과 복원

브라우저 자동 저장은 보조 기능입니다. 사진이 많거나 브라우저 데이터를 지우면 저장되지 않을 수 있으니 JSON도 보관하세요. 다른 브랜드 키트 편집본과는 별도 형식입니다.

공개 전 확인

고객·협업자의 공개 동의, 사진·상표·음악·영상의 권리, 맡은 역할과 결과 수치의 근거를 확인하세요. 공개할 수 있는 연락처만 넣으세요.

포함하지 않는 기능

파일 자체에 문의 수집, 회원·결제, 서버 저장, 영상·음악 파일 업로드 기능은 없습니다. 영상·음악 등은 실제 외부 링크로 연결합니다. 온라인 호스팅과 개인 도메인 연결은 별도입니다.

작업을 눌러 상세를 확인해 보세요
입력 정보·이미지는 외부 서버로 전송하지 않습니다. 미리보기와 저장한 HTML에 같은 작업 필터·상세 기능이 적용됩니다.
